# Microsoft Research

> Developers of the **Phi model series** — the most prominent demonstration that synthetic data quality can substitute for model scale. Also major contributors to AI safety, code generation (Copilot), and the Azure AI infrastructure.

## Key Contributions
- **Phi model series** (Phi-1 → Phi-4) — proving data quality > parameter count
- Pioneered systematic use of **synthetic data in pretraining** (not just fine-tuning)
- **Pivotal Token Search** — novel DPO data selection method (Phi-4)
- Major investments in AI infrastructure (Azure, GitHub Copilot, Bing)
- Contributions to responsible AI tooling and red-teaming practices
