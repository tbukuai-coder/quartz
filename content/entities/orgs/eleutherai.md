# EleutherAI

> A grassroots **open-source AI research collective** that pioneered community-driven LLM development — creating GPT-NeoX, The Pile, and the lm-evaluation-harness used by the entire ecosystem.

## Overview
EleutherAI formed in 2020 as a Discord server of researchers frustrated by GPT-3's closed nature. They organized to replicate and open-source large language models, creating influential models (GPT-Neo, GPT-NeoX-20B, Pythia), datasets (The Pile), and evaluation tools (lm-evaluation-harness).

## Key Contributions

### Models
- **GPT-Neo** (2021) — First open GPT-3 replication (1.3B, 2.7B)
- **GPT-NeoX-20B** (2022) — Largest fully open model at release
- **Pythia** (2023) — 70M–12B suite with all checkpoints for scientific study

### Datasets
- **The Pile** (2020) — 800GB diverse English text (Arxiv, GitHub, books, web, legal, medical)

### Tools
- **lm-evaluation-harness** — Standard LLM evaluation tool (used by HF Open LLM Leaderboard)

## Significance
Proved volunteer-organized research can produce competitive frontier models. Pythia's open checkpoints inspired [[entities/models/olmo|OLMo]]'s approach.
