# OpenAI

> Defined the **RLHF alignment paradigm** with InstructGPT, pioneered **process reward models** with "Let's Verify Step by Step," and set the template that the open-source community has been iterating on ever since.

## Key Contributions
- **InstructGPT** — established the SFT → Reward Model → PPO pipeline ([[sources/instructgpt]])
- **GPT series** (GPT-2, GPT-3, GPT-4, o1, o3) — advancing language model capabilities
- **Process Reward Models** — proved step-level supervision beats outcome supervision for reliable reasoning ([[sources/lets-verify-step-by-step]])
- **PRM800K** — 800K step-level human labels for reward model training
- **Whisper** — robust speech recognition model ([[sources/whisper]])
- Defined the problem of AI alignment in practical terms
