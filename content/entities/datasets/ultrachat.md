# UltraChat

> A large-scale, multi-round dialogue dataset generated by ChatGPT — used as the SFT training data for [[entities/models/zephyr|Zephyr]] and many other open-source chat models.

## Overview
UltraChat contains ~1.5M multi-turn dialogues covering diverse topics, generated by having two ChatGPT instances converse. It provides the instruction-following training signal in the distilled SFT (dSFT) stage of alignment pipelines.

## Key Details
- **Size**: ~1.5M conversations
- **Generation**: Two ChatGPT instances in conversation
- **Topics**: World knowledge, creative writing, data analysis, coding, math, and more
- **Format**: Multi-turn dialogue (messages format)
- **HF Hub**: [stingning/ultrachat](https://huggingface.co/datasets/stingning/ultrachat)
- **Filtered version**: UltraChat-200k (used by Zephyr)
