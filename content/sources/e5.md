# E5 — Text Embeddings by Weakly-Supervised Pre-training

> A family of general-purpose text embedding models trained on 1.3B weakly-supervised web text pairs — bridging SBERT-era and LLM-era embeddings. 4M+ HF downloads. Established the "query:"/"passage:" prefix pattern.

## Key Contributions
- **CCPairs dataset**: 1.3B text pairs curated from Common Crawl using consistency-based filtering — the largest weakly-supervised embedding training set
- **Instruction prefix pattern**: "query: ..." and "passage: ..." prefixes that all modern embedding models (Nomic, GTE, BGE) adopted
- **General-purpose embeddings**: Single model works for retrieval, clustering, classification, STS without task-specific fine-tuning
- **MTEB standardization**: Among the first to comprehensively evaluate on the MTEB benchmark, helping establish it as the standard

## Method
1. **Data curation** (CCPairs): Scrape (title, passage), (question, answer), (query, document) pairs from Common Crawl. Filter by consistency: if two different queries retrieve the same passage, the pair is likely high-quality
2. **Contrastive pre-training**: Train on CCPairs with InfoNCE loss + hard negatives (in-batch + mined)
3. **Instruction prefixes**: Prepend "query: " to queries and "passage: " to documents — helps model distinguish retrieval intent from general text
4. **Fine-tuning** (optional): Further train on labeled retrieval datasets (MS MARCO, NQ, etc.) for domain-specific improvements
5. **Model sizes**: E5-small (33M), E5-base (109M), E5-large (335M), E5-mistral-7b-instruct (7B)

## Results
- **BEIR (zero-shot retrieval)**: First neural model to beat BM25 across all BEIR datasets
- **MTEB**: State-of-the-art across retrieval, clustering, classification, STS
- E5-mistral-7b-instruct: LLM-based embeddings matching or exceeding specialized models
- Instruction prefixes provide 2-5% improvement over no-prefix baselines
