# Zephyr: Direct Distillation of LM Alignment

> Showed that a **7B model can be aligned entirely with AI feedback** (no human annotation), using distilled SFT + distilled DPO to produce a chat model that tops MT-Bench among open 7B models.

## Key Contributions
- Introduced **dSFT** (distilled SFT): fine-tune on outputs generated by a stronger teacher model
- Introduced **dDPO** (distilled DPO): use AI-generated preference rankings instead of human labels
- Achieved **#1 on MT-Bench** among 7B models at time of release (7.34)
- Demonstrated that **no human annotation** is needed for competitive alignment
- Released as part of the Hugging Face **Alignment Handbook** — a practical guide for reproducing alignment

## Method
Three-stage pipeline starting from [[sources/mistral-7b]]:

1. **dSFT (Distilled Supervised Fine-Tuning)**:
   - Use GPT-4 to generate high-quality responses to the UltraChat dataset prompts
   - Fine-tune Mistral 7B on these responses
   
2. **dDPO (Distilled Direct Preference Optimization)**:
   - Use GPT-4 to score/rank multiple responses to the same prompt (UltraFeedback dataset)
   - Apply DPO on these AI-generated preference pairs
   - No human annotators involved at any stage

3. **AIF (AI Feedback)**:
   - The entire preference signal comes from a stronger model (GPT-4), not humans
   - This makes the pipeline cheap, fast, and reproducible

## Results
- **MT-Bench**: 7.34 — best 7B model at time of release
- Outperforms Llama 2-Chat 70B on MT-Bench (!) — a 10× smaller model
- Competitive with significantly larger models on chat quality
