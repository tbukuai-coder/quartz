# Demystifying RL in Agentic Reasoning

> A comprehensive empirical study of RL for **agentic reasoning** — investigating data, algorithms, and reasoning modes for tool-using LLM agents. Key findings: real end-to-end trajectories beat synthetic data, exploration-friendly techniques (clip-higher, entropy management) are crucial, and a **deliberative strategy** with fewer but more thoughtful tool calls outperforms frequent tool use. With these recipes, **4B models surpass 32B models** in agentic reasoning.

## Key Contributions
- **Real vs synthetic data**: Replacing stitched synthetic trajectories with **real end-to-end tool-use trajectories** yields a far stronger SFT initialization — synthetic data misses critical decision points at tool invocation boundaries
- **Exploration-friendly RL techniques**: Clip-higher, overlong reward shaping, and maintaining adequate policy entropy are crucial for agentic RL (GRPO-TCR recipe)
- **Deliberative strategy**: A reasoning mode with fewer tool calls but more internal deliberation outperforms both frequent-tool-call and verbose self-reasoning approaches — improving tool efficiency and accuracy
- **Model-aware datasets**: RL data should be filtered based on the specific model's capability — questions too easy or too hard for the model waste training signal
- **Strong small models**: 4B-sized models with these recipes achieve superior agentic reasoning compared to 32B models
- **Open contributions**: 3K high-quality end-to-end agentic SFT dataset + 30K diverse RL dataset

## Method
### Data Curation
- **SFT**: 3K real end-to-end trajectories generated by Qwen3-Coder-30B-A3B via Qwen-Agent + SandBoxFusion code interpreter. Sources: s1-1K, DAPO-Math, Skywork-OR1, science problems
- **RL**: 30K diverse samples (17K math, 4.9K math from Skywork, 3.6K code, 3K science)
- **Model-aware filtering**: 8-candidate sampling per problem; remove all-fail and all-pass questions to keep only questions at the model's learning frontier

### Algorithmic Recipes
Three GRPO variants compared:
- **GRPO-TCR**: Token-level loss + Clip-higher + overlong Reward shaping (best recipe)
- **GRPO-SCR**: Sample-level + Clip-higher + Reward shaping
- **GRPO-T**: Token-level only (baseline)

### Reasoning Modes
- **Frequent tool calls**: Many short tool interactions
- **Verbose self-reasoning**: Long internal thinking with occasional tool use
- **Deliberative (best)**: Careful internal reasoning → targeted tool call → verify → conclude

## Results
### Agentic Reasoning (Qwen3-4B)
| Benchmark | Base | After SFT | After RL (GRPO-TCR) |
|---|---|---|---|
| AIME 2024 (agentic) | — | 42.3 | **57.1** |
| AIME 2025 (agentic) | — | 30.8 | **43.0** |
| GPQA-Diamond | — | 45.4 | **56.1** |
| LiveCodeBench-v6 | — | 37.2 | **47.5** |

### Key Ablations
- Real trajectories vs synthetic: +8–12% across benchmarks
- Clip-higher: consistent improvement on all tasks
- Overlong reward shaping: prevents degeneration from excessively long rollouts
- High-diversity data: maintains policy entropy, sustains exploration across training
- Deliberative mode outperforms frequent-tool and verbose-reasoning modes
